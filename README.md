# Decodelabs Internship

This repository documents my UX/UI design internship projects, research, design processes, and key deliverables completed during the Decodelabs Internship.

## Projects

### 01 — Fitness App Startup
A UX research and product design project focused on time-poor professionals working 40+ hour weeks who struggle to make exercise part of their daily routine.

**Key Deliverables**
- Problem Identification
- Target Audience
- User Personas
- Empathy Map
- Pain Points & Behavioural Insights

### 02 — E-commerce UX Design
A UX design project focused on simplifying a cluttered e-commerce experience through clearer navigation, information hierarchy, user flow, and responsive homepage wireframing.

**Key Deliverables**
- Problem Identification
- Target Audience
- Pain Points & Behavioural Insights
- Information Architecture
- User Flow
- Homepage Low-Fidelity Wireframe
